# Domain Packs

Select one primary pack per assignment. Add at most one secondary pack when the product genuinely combines surface types. Record the selection in `DECISIONS.md`.

A domain pack changes priorities; it is not merely a style preset. For example, an expressive marketing shell may use editorial composition, while the authenticated dashboard still follows SaaS and enterprise task rules.
